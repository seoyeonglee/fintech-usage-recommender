# FinScope Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user explicitly requested continuing implementation in this session.

**Goal:** Ship an interactive, measured fintech recommendation portfolio demo.

**Architecture:** Pure TypeScript data generation, analytics, ranking and evaluation modules are shared by the browser and Node tests/evaluator. React presents their results. Render serves only built static files.

**Tech Stack:** React 18, TypeScript 5.9, Vite 6, Node native test runner, Playwright.

**Spec:** ../specs/2026-10-02-finscope-design.md

## Global Constraints
- Eight fictional apps; 320 users; 84 days; end date 2026-09-30; seed 2401.
- Train days 0..69; holdout days 70..83; K=3; no paid dependencies or APIs.
- Static deploy only; no custom domain or account billing changes.

## Review Focus
- Zero cohorts/events must not produce NaN or misleading retention denominators.
- Zero or negative/nonfinite weights must be normalized safely.
- Exclusions must leave a stable empty/cold-start result rather than duplicate apps.
- Fitting cannot consume future data; evaluation never tunes on its holdout.
- Narrow viewports and reduced-motion/keyboard use remain usable.
